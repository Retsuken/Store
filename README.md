# 👕 FashionStore — Clothing E-Commerce Platform

A modern online clothing store built with Django. The platform provides full-featured e-commerce functionality including product catalog, shopping cart, order processing, user accounts, and admin panel.

## ✨ Key Features

### For Customers:
- 🛍️ **Product Catalog** — Browse products with filtering by categories, sizes, colors, and prices
- 🔍 **Search** — Convenient search by name, description, and SKU
- 🛒 **Shopping Cart** — Add/remove items, update quantities
- 💳 **Checkout** — Multi-step process with delivery and payment options
- 👤 **User Dashboard** — View order history, manage profile
- ⭐ **Reviews & Ratings** — Rate products and leave reviews
- ❤️ **Wishlist** — Save favorite products
- 📊 **Recommendations** — Personalized product recommendations

### For Administrators:
- 📦 **Product Management** — Add/edit/delete products, manage inventory
- 🏷️ **Category Management** — Create hierarchical category structure
- 📋 **Order Management** — View and update order statuses
- 👥 **User Management** — Moderation and permission management
- 📊 **Sales Analytics** — Sales reports, popular products
- 🖼️ **Media Management** — Upload and manage product images

## 🛠️ Tech Stack

- **Python 3.10+** — Programming language

- **SQLite** — Database
